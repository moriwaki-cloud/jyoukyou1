# 診療情報連携共有料 照会用紙 作成支援アプリ

歯科医院向けに、「診療情報連携共有に係る照会」用紙（日本歯科医師会様式）の作成を支援するPWA（Progressive Web App）です。
治療内容の選択から文言生成、照会先医療機関の選択、内容確認、PDF作成・共有までを1つの流れでサポートします。

フレームワーク不使用（素のHTML/CSS/JavaScript）、外部ライブラリはPDF生成のhtml2pdf.jsのみ使用しています。

## 画面構成・進行ステップ

アプリは以下の4ステップで構成されています。ヘッダー下のステップバーで現在地が確認できます。

1. **患者情報・治療内容**：患者情報の入力、治療内容の選択、文言の自動生成
2. **医療機関選択**：照会先の医科医療機関を選択（未登録なら新規登録）
3. **内容確認**：照会先・照会元・生成文言の最終確認
4. **PDF・共有**：用紙イメージの最終プレビュー編集、PDF作成、共有・印刷

「設定」メニュー（①の画面右上）から、医科医療機関マスターの管理・自院情報の編集にいつでもアクセスできます。

## ローカルでの起動方法（開発・確認用）

Node.jsがある場合：

```
cd "C:\Users\moriwaki\Desktop\アプリ"
npx serve .
```

表示されたURL（例: http://localhost:3000）をブラウザで開いてください。

Pythonがある場合：

```
cd "C:\Users\moriwaki\Desktop\アプリ"
python -m http.server 8000
```

`http://localhost:8000` を開いてください。

※ `index.html` を `file://` で直接開くと、treatments.jsonの読み込みやService Workerの登録が失敗するため、必ずローカルサーバー経由で確認してください。
※ PDF生成ライブラリ（html2pdf.js）はCDNから読み込むため、**初回起動時はインターネット接続が必要**です。

## ホーム画面への追加（PWAインストール）

### iPhone（Safari）

1. Safariでアプリを開く
2. 下部の共有ボタン（□に↑のアイコン）をタップ
3. 「ホーム画面に追加」を選択
4. アイコン・名前（情共照会文言作成）を確認して「追加」

※ iPhoneでは**Safari以外のブラウザ**（Chrome等）では「ホーム画面に追加」メニューが表示されません。

### Android（Chrome）

1. Chromeでアプリを開く
2. 右上のメニュー（⋮）をタップ
3. 「アプリをインストール」または「ホーム画面に追加」を選択

## 動作確認シナリオ

### 1. 初回起動・自院情報の登録

1. 初めてアプリを開くと、自院情報の初期設定画面が表示されることを確認
2. 照会元歯科医療機関名（必須）、歯科医師氏名、所在地、電話番号を入力して保存
3. 治療内容選択画面（ステップ①）に遷移することを確認

### 2. 一連の照会作成フロー（通し確認）

1. **①患者情報・治療内容**：患者氏名（必須）・性別・生年月日・住所・電話番号を入力し、治療内容を複数選択して「文言を生成」→ 内容を確認し「次へ」
2. **②医療機関選択**：登録済みの医療機関から選択、または「＋ 新しい医療機関を登録する」で新規登録（医療機関が0件の場合は自動的に登録フォームが表示される）
3. **③内容確認**：照会先・照会元の情報と生成文言を確認し、必要であれば文言を編集して「次へ」
4. **④PDF・共有**：用紙イメージのプレビューを確認し、必要な項目があれば直接タップして編集
5. 「PDFを共有・印刷する」（Web Share API非対応環境では「PDFをダウンロードする」）をタップし、PDFが正しく作成・共有／ダウンロードされることを確認

### 3. 未入力チェック（バリデーション）の確認

- 患者氏名を空欄のまま「次へ」→ 入力欄の下にエラーメッセージが表示され、次の画面に進めないことを確認
- 治療内容を1つも選択せずに「次へ」→ エラーメッセージが表示されることを確認
- 治療内容を選択しても「文言を生成」を押さずに「次へ」→ エラーメッセージが表示されることを確認
- 医療機関が1件も登録されていない状態で「次へ」→ 選択画面の代わりに登録フォームが表示されることを確認（医療機関名は入力必須）

### 4. 「新しい照会を作成する」の確認

1. ④の画面まで進み、「新しい照会を作成する」をタップ
2. ①の画面に戻り、患者氏名・性別・生年月日・住所・電話番号、治療内容の選択、生成文言がすべて空欄・未選択にリセットされていることを確認
3. 「設定」→「医科医療機関マスターの管理」を開き、登録済みの医療機関が**消えずに残っている**ことを確認
4. 「設定」→「自院情報の編集」を開き、自院情報が**消えずに残っている**ことを確認

### 5. オフライン動作の確認

1. 一度インターネット接続がある状態でアプリを開き、一通り操作する（Service Workerがファイル一式をキャッシュします）
2. ブラウザの開発者ツール等で「オフライン」に切り替える（または機内モードにする）
3. アプリを再読み込みし、画面遷移・治療内容選択・文言生成・マスター参照ができることを確認
4. PDF作成については、html2pdf.js（CDN）がキャッシュ済みであればオフラインでも動作します。初回オンライン時にバックグラウンドでキャッシュされるため、**2回目以降のオフライン利用**で確認してください（何らかの理由でキャッシュに失敗している場合はオンライン時のみ動作します）

## iPhone Safari / Android ブラウザでの注意点

### 共有・印刷

- Web Share API（`navigator.share`、ファイル共有）に対応した環境では、「PDFを共有・印刷する」ボタンでOS標準の共有シートが開きます。そこからAirPrint対応プリンタや院内のプリンタアプリを選んで印刷できます（アプリ側で特定プリンタとの連携は行っていません）。
- iPhone Safariはファイル共有に対応しています（iOS 15以降を推奨）。
- Web Share APIに対応していない環境（一部のAndroidブラウザ、PCのブラウザ等）では、ボタンの表示が自動的に「PDFをダウンロードする」に変わり、タップするとPDFファイルが端末にダウンロードされます。
- 共有シートを開いた後に「キャンセル」した場合はダウンロードされません（再度ボタンを押してください）。共有自体が失敗した場合は自動的にダウンロードにフォールバックします。

### PWAインストール

- iPhoneは**Safari**からのみホーム画面に追加できます。
- Androidは主要ブラウザ（Chrome、Edgeなど）からインストール可能です。

### 画面表示

- 縦画面（ポートレート）での利用を想定しています。
- 最終プレビューのA4用紙イメージは画面幅に応じて自動縮小表示されます。

## データの取り扱いについて

- 患者情報（氏名・性別・生年月日・住所・電話番号）、医科医療機関マスター、自院情報は、**すべて端末内のブラウザのlocalStorageにのみ保存**されます。
- 外部サーバーへの自動送信・自動バックアップは一切行っていません（本アプリにはサーバー通信を行うコードは含まれていません。PDF生成ライブラリの読み込み以外に外部との通信は発生しません）。
- 「新しい照会を作成する」（③内容確認画面の「はじめから」、④PDF・共有画面の「新しい照会を作成する」）は、患者情報・治療内容の選択・生成文言・選択中の医療機関のみをリセットします。**医科医療機関マスター・自院情報はリセットされません**。
- ブラウザのキャッシュ・サイトデータを削除すると、保存された医療機関マスター・自院情報も削除されるのでご注意ください。

## ファイル構成

```
index.html              画面一式（治療内容選択〜最終プレビューまでの全画面）
style.css                スタイル一式
treatments.json          治療内容と文言候補のマスターデータ
manifest.json            PWAマニフェスト
service-worker.js        オフラインキャッシュ
icons/                   アプリアイコン（SVG・PNG）
js/
  storage.js              localStorage CRUD（医療機関マスター・自院マスター）
  nav.js                  画面遷移・戻るスタック
  treatment.js            治療内容選択・文言生成ロジック
  institution.js          医療機関の選択・登録・編集・削除
  clinic.js               自院情報の初回設定・編集
  finalpreview.js         最終プレビューの差し込み・チェック欄マッピング・PDF共有
  main.js                 画面配線・ステップ表示・バリデーション・初期化
```
